✋ Hand Tracking – Part 2

An advanced real-time Hand Tracking project built using HTML, CSS, JavaScript, and MediaPipe Hands. This project uses webcam-based hand detection to create interactive visual effects and animations through hand gestures.

 Features

- Real-Time Hand Tracking: Detects and tracks up to two hands using a webcam.
- 21 Hand Landmarks: Tracks hand joints and finger positions.
- Zigzag Gesture: Move your hand in a zigzag pattern to generate energy orbs.
- Energy Sphere:Bring both palms together to charge an energy sphere.
-Shockwave Effect: Pull your hands apart to release a powerful visual shockwave.
-Mystic Mandala: Open your palm to generate animated mandala patterns.
-Lightning Effect: Pinch your thumb and index finger to create lightning effects.
- **Interactive Orbs:** Touch the energy orbs to push them around and combine them.
-Particle System: Generates glowing particles and dynamic visual trails.
-Camera Controls:** Switch between Dim, Off, and Bright camera modes.
-Clear Orbs:** Remove generated orbs and visual effects using the Clear Orbs button.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- MediaPipe Hands
- HTML5 Canvas API
- WebRTC (getUserMedia API)

How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Click the **Start Camera** button.
5. Allow webcam access when your browser asks for permission.
6. Show your hands in front of the camera.
7. Perform different hand gestures to explore the visual effects.

Note: Camera access requires HTTPS or localhost in supported browsers.
